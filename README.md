# tesbota

**The Eldest Scrolls: Boltzmann Tamagotchi.** An adventurer wakes with no memory in a world that has not been written yet, and the world gets invented around it one contested document at a time, mostly while you are asleep. A chain of separated agents does the work: an explorer that only ever sees narration, a game master that adjudicates its actions, lore masters that check every claim against canon and fill the silences, and a narrator that appends each finished turn to the adventurer's life story. Each layer sees only what the driver hands it, so the separation is structural rather than a rule anyone is asked to respect.

There is no codex. `canon.db` is a pile of books by authors who are biased, mistaken or lying, and nothing becomes true by assertion, only by attribution. Only the godhead, who states the world's laws, and the Narrator, who records what actually happened, can't be wrong. The world runs on node with no build step: enter `nix-shell`, run `npm install` in `cli/`, then drive it with `node cli/src/index.ts init`, `step` and `status`, or watch and steer it through the Next.js interface in `web/`.
